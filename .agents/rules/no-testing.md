# Regla: Prohibición de Pruebas Automáticas

## Restricción Obligatoria
El asistente **NUNCA** debe ejecutar pruebas automáticamente:
- **NO** usar `browser_subagent` ni abrir navegadores para comprobar interfaces o flujos.
- **NO** lanzar comandos de prueba automáticos ni simular interacciones de testing en el navegador o terminal a menos que el usuario lo pida explícitamente.
- El usuario es quien realiza **todas** las pruebas y revisiones visuales por su cuenta.
- El rol del asistente es diseñar, codificar, estructurar y explicar claramente los cambios realizados.
