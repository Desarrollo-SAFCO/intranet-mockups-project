# Reglas Generales del Proyecto

## Prohibición de Pruebas Automáticas
- **NUNCA ejecutar pruebas por cuenta propia.**
- El asistente no debe invocar herramientas de testing en el navegador (`browser_subagent`), ni abrir páginas para probar funcionalidades por sí mismo.
- **Todas las pruebas, comprobaciones visuales e interacciones en el navegador las realizará exclusivamente el usuario.**
- Limitarse a editar, generar código, estructurar soluciones y explicar con claridad las modificaciones.
